# Internal incident register

15 October2026. Migration4751 adds a durable bounded staff incident register for control-plane, mail-plane, backup and payment symptoms. Only verified persisted operators with recent session MFA may open, acknowledge or resolve; viewers may inspect. No freeform customer data/secrets are accepted. A partial unique index prevents duplicate active component/symptom incidents. State transitions require the observed version; concurrent acknowledgements admit one winner and stale resolutions fail409. Resolution requires acknowledgement first and records a timestamp. Every successful mutation writes a platform audit event atomically.

Staff UI exposes role-appropriate controls and distinguishes durable local synthetic alerts from unconfigured external delivery. Resolution is a human status decision, not proof that a provider recovered. Migration4758 queues one immutable fixed-code alert for every incident version transition; an explicitly enabled local worker provides leased retry and idempotent digest-only delivery. Hashed process heartbeats expose fresh, expired or degraded observations without storing hostnames. Tests verify viewer denial, duplicate prevention, transition ordering, concurrent version fencing, exact audit/alert counts, replay safety, heartbeat expiry and runtime-role separation.

Remaining: production heartbeat exporters, automated observation-to-incident policy, real alert destinations/escalation, maintenance windows, and owner-reviewed on-call/SLO/runbook policy. Real destinations and paid services remain approval-gated.
