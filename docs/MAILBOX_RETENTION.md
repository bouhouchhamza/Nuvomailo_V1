# Reversible mailbox retention

15 October2026. Migration4750 adds a retained timestamp with a database invariant requiring suspended desired authentication state. Owner-only retention reserves the existing mailbox/address/quota and queues the existing revision-fenced suspension operation. Repeated retention is a no-op; generic quota/resume changes are rejected until the explicit owner restoration flow. Restoration clears retention and queues a new active revision in the same transaction. Pending one-time credential grants are revoked on either transition. Neither operation removes provider accounts, mail, queues, routes, encrypted artifacts or audit evidence.

This is authentication suspension intent, not confirmed provider state or inbound suspension. The isolated lab previously verified that authentication-disabled mailboxes can continue receiving mail. Retention deliberately preserves that delivery behavior, including existing aliases targeting the mailbox; accepted messages remain stored. Older queued messages remain under the provider's normal delivery rules. Do not describe retention as deletion, inbound rejection or immediate session cancellation. Default applications still have no enabled mail provider; the response explicitly reports providerApplied:false.

Retention is indefinite; no timer schedules a purge. Reserved quotas continue counting against entitlements. Owners can restore only when domain custody is active and verified. Domain suspension/reverification must be resolved before restoring a mailbox. Tests verify role denial, idempotency, DB invariant, blocked generic resume and separate revisioned restore. No new provider deletion behavior was added or claimed tested.

Remaining: actual provider usage synchronization, reviewed retention duration/legal hold policy, independently authenticated deletion requests with a recovery window, provider-specific backup/restore and purge conformance, and deliberate inbound policy controls. Permanent deletion/deprovision is unavailable and must not be inferred from a retention timestamp.
